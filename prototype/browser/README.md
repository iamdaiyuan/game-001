# 《小城烟火》30 分钟原型 Demo

一个可直接在浏览器里玩的竖屏小游戏原型，用于验证：

- 二合 + 订单 + 改造 + 剧情的核心循环
- “改造前后”的视觉爽感
- 现代中国市井题材对 25–45 岁女性的吸引力
- 6 元首充 / 激励视频 / 分享卡的早期意愿

> 这是原型，不是正式游戏。所有支付、广告均为模拟，不会产生真实扣款或请求真实广告。

---

## 快速开始

在项目根目录执行：

```bash
cd demo
python3 -m http.server 4173
```

然后打开：

```
http://127.0.0.1:4173
```

建议使用 Chrome / Safari 的移动端模拟器，尺寸 390×844 或 375×667。

> 直接双击 `index.html` 可能因 ES Module 的跨域限制无法加载，请用本地服务器。

---

## 怎么玩

1. 点“开始新游戏”，看完 4 格序章。
2. 点底部「旧物箱」产出物品。
3. 点两块**一样**的物品：先点一块，再点另一块，即可合成。
4. 完成上方订单，获得铜钱。
5. 攒够 300 铜钱，点「改造」修门头。
6. 继续做订单、解锁「食材篮」、改造柜台和墙面。
7. 三个区域都改完后，点「开门营业」看结局。
8. 结局可以生成分享卡、填写 3 题问卷。

### 小提示

- 棋盘满了点「整理」。
- 体力不足时点顶部体力条，或等自然恢复。
- 顶部钻石按钮可以打开 6 元首充（模拟）。
- 点右上角 🎒 看旧物与图鉴，⚙️ 看设置、导出数据、重新开始。

## 已实现

| 模块 | 说明 |
|---|---|
| 序章 | 4 格漫画式叙事 |
| 二合棋盘 | 7×7、2 条产出器、2 条 6 级物品链、30 个物品 |
| 订单 | 12 个订单、3 个槽位、逐步解锁、特殊物品需求 |
| 改造 | 3 个区域 × 3 个方案、前后对比滑块、分享卡 |
| 剧情 | 6 个节点、约 20 句对话、可跳过 |
| 经济 | 铜钱、体力、钻石、零件、口碑 |
| 变现测试 | 6 元首充（模拟）、激励视频（模拟）、钻石换体力 |
| 分享 | Canvas 生成 1080×1440 分享卡，可保存/复制文案 |
| 背包 | 特殊物品、图鉴 |
| 结局 | 统计、下一章预告、3 题问卷 |
| 存档 | localStorage 自动保存、继续游戏 |
| 音效 | WebAudio 合成，无外部音频文件 |
| 数据 | 全流程事件记录，可在设置中导出 JSON |
| 调试 | URL 加 `?debug=1` 打开调试面板 |

## 与需求文档的差异

| 需求文档 | Demo 实现 | 原因 |
|---|---|---|
| 7×9 棋盘、35 格解锁 | 7×7、49 格 | 竖屏空间与操作舒适度 |
| 30 分钟完整流程 | 约 15–30 分钟 | 内容量按 12 单/3 改造压缩 |
| 3 个订单槽 | 已实现，逐步解锁 | — |
| 2 个产出器 | 已实现（旧物箱、食材篮） | — |
| 30 个物品 | 已实现 | — |
| 9 个改造方案 | 已实现 | — |
| 6 个剧情节点 | 已实现 | — |
| 真实支付/广告 | 模拟 | 原型阶段不接真实商业能力 |
| 微信/抖音双端构建 | 浏览器版 | 先验证体验，再接 Cocos/平台 SDK |
| 后端存档/排行榜 | 本地存档 | 原型阶段不搭后端 |

## 调试

打开：

```
http://127.0.0.1:4173/?debug=1
```

- 左上角显示 `DEBUG` 事件计数
- 设置里出现调试按钮：加铜钱、加体力、完成订单、加改造资源、首充、广告
- 设置里可导出完整状态 JSON（含事件记录）

## 已知限制

- 没有真实后端、排行榜、好友系统。
- 没有真实微信/抖音 SDK、支付、广告。
- 棋盘交互是“点选合成”，没有拖拽；移动端点击更稳。
- 美术为 CSS/emoji 占位，正式版需替换为手绘资产。
- 音效为合成音，正式版需替换为音乐/音效资产。
- 没有做低端机性能压测、包体拆分、CDN 加载。
- 剧情文本为 Demo 版，正式版需扩写与校对。
