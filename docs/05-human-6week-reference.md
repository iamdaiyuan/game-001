## 0. 使用说明

这份 Backlog 是“可执行版”，不是概念排期。每个 Sprint 包含：

- Sprint Goal
- 任务表（负责人、估算、依赖、验收标准）
- 每日计划
- Sprint Demo / 出口标准
- 风险与应对

估算单位：**PD（Person-Day，人天）**。  
团队按 13 人、每周 5 天、15% 缓冲计算，单 Sprint 计划容量约 **50–55 PD**。

> 浏览器版 Demo 已经可玩，作为“可玩设计稿”保留：Cocos 版复用它的配置、交互流程、视觉参考与测试脚本，但不直接复用 JS 代码。

## 1. 6 周目标与范围

### 1.1 6 周目标

> 把浏览器原型迁移为 **Cocos Creator 3.8 + TypeScript** 的微信小游戏 Demo，完整跑通“序章 → 二合 → 订单 → 改造 → 剧情 → 首充/广告 → 结局 → 分享/问卷”30 分钟流程，并完成 20 人用户测试与 G1 评审。

### 1.2 交付物

| # | 交付物 | 说明 |
|---|---|---|
| 1 | 微信小游戏 Demo 包 | 微信开发者工具可打开，真机可玩 |
| 2 | 抖音小游戏构建包 | 仅验证构建/性能，不做完整适配 |
| 3 | 30 分钟完整流程 | 第 1 章“外婆的杂货铺” |
| 4 | 20 人测试数据 | 录屏、访谈、问卷、埋点 |
| 5 | G1 测试报告 | 定量 + 定性 + 问题清单 |
| 6 | Go / Iterate / Kill 决议 | 进入 M3 或调整方向 |
| 7 | 可复用资产 | 配置表、UI 套件、角色、物品、音频 |

### 1.3 不在范围（防止范围蔓延）

- 第 2 章、多店铺街区、好友/排行榜/公会。
- 正式商业化：月卡、通行证、抽卡、完整礼包。
- 正式版号/真实支付/真实广告；Demo 用沙盒 + 测试广告位。
- PC 端、多语言、3D、Live2D、全语音。
- 抖音完整适配；只做构建与性能抽测。
- 大规模后端；Demo 用轻量服务 + 本地缓存。
